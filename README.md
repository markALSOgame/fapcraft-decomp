# Fapcraft (com.trolmastercard.sexmod)

[English README](README.md) | [Русская версия](README_RU.md)

Decompiled copy of the Minecraft Forge 1.12.2 mod **Fapcraft** (`com.trolmastercard.sexmod`, TMC 1.1.0).

## Contents

| Path | Description |
|------|-------------|
| `com/trolmastercard/sexmod/` | Decompiled mod sources (Java files) |
| `assets/` | Mod resources: Geo models, textures, animations, sounds, lang |
| `fapcraft-1.1.0.jar` | Pre-built mod jar |
| `mcmod.info`, `pack.mcmeta` | Mod metadata |

## Install

Copy `fapcraft-1.1.0.jar` into the `mods/` folder of a Minecraft 1.12.2 + Forge 14.23.5.2847 installation.
