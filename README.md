# Fapcraft (com.trolmastercard.sexmod)

[English README](README.md) | [Русская версия](README_RU.md)

Decompiled copy of the Minecraft Forge 1.12.2 mod **Fapcraft** (`com.trolmastercard.sexmod`, TMC 1.1.0).

## About

Fapcraft is a mod for Minecraft 1.12.2 that adds NPC characters (girls) you can interact with. Features:

- **12 unique characters**: Allie, Bia, Ellie, Jenny, Luna, Galath, Goblin, Kobold, Slime, Bee, Cat, Manglelie
- **Tribe system**: recruit characters to your tribe, build homes for them
- **Customization**: change character appearance, clothing, colors
- **Geo models**: uses GeckoLib for animations and models
- **Sounds**: each character has unique sounds and voices
- **Items**: magic staffs, summoning eggs, coins, and more

## Install

1. Install Minecraft 1.12.2
2. Install Forge 1.12.2-14.23.5.2847
3. Copy `fapcraft-1.1.0.jar` into the `mods/` folder
4. Launch the game

## Requirements

- Minecraft 1.12.2
