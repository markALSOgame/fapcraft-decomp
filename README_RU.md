# Fapcraft (com.trolmastercard.sexmod)

[English README](README.md) | [Русская версия](README_RU.md)

Декомпилированная копия мода для Minecraft Forge 1.12.2 — **Fapcraft** (`com.trolmastercard.sexmod`, версия TMC 1.1.0).

## О моде

Fapcraft — это мод для Minecraft 1.12.2, добавляющий в игру NPC-персонажей (девушек), с которыми можно взаимодействовать. Мод включает в себя:

- **12 уникальных персонажей**: Allie, Bia, Ellie, Jenny, Luna, Galath, Goblin, Kobold, Slime, Bee, Cat, Manglelie
- **Система племён**: присоединяйте персонажей к своему племени, стройте для них дома
- **Кастомизация**: изменяйте внешний вид персонажез, одежду, цвета
- **Гибкие модели**: используется GeckoLib для анимаций и моделей
- **Звуки**: у каждого персонажа есть уникальные звуки и голоса
- **Предметы**: волшебные палочки, яйца призыва, монеты и другие предметы

## Установка

1. Установите Minecraft 1.12.2
2. Установите Forge 1.12.2-14.23.5.2847
3. Скопируйте `fapcraft-1.1.0.jar` в папку `mods/`
4. Запустите игру

## Требования

- Minecraft 1.12.2
- Forge 1.12.2-14.23.5.2847
- GeckoLib (встроен в jar-файл мода)
